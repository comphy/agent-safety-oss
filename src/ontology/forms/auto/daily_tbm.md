> **📝 작성 가이드**:
>
> **[문서번호]**

>   - DOC-260429-01
>

> - YYYY-MM-DD.

> - 성명·직책.

## 2. TBM 회의록 (Tool Box Meeting) (위험성평가 고시 제15조 ④ 3호 + KOSHA P-103)

| 항목 | 내용 |
|---|---|
| TBM 일시 *(필수)* | |
| 진행자 (관리감독자) *(필수)* | |
| 오늘의 작업 *(필수)* | |
| 잠재 위험요인 (3건 이상) *(필수)* | |
| 오늘의 중점 안전수칙 *(필수)* | |
| 작업 전 안전조치 확인 (3건) *(필수)* | |
| 참석자 명단·서명 *(필수)* | |

> **📝 작성 가이드**:
>
> **[TBM 일시]**
> - 매 작업일 시작 전.
> - 예시:
>   - 2026-04-29 07:30
>
> **[진행자 (관리감독자)]**
> - 관리감독자 또는 작업지휘자.
> - 예시:
>   - 박감독
>
> **[오늘의 작업]**
> - 오늘 시행할 작업·위치·인원.
> - 예시:
>   - A동 6층 외벽 도장 + B동 굴착, 작업자 12명
>
> **[잠재 위험요인 (3건 이상)]**
> - 오늘 작업의 핵심 위험.
> - 예시:
>   - [object Object],[object Object],[object Object]
>
> **[오늘의 중점 안전수칙]**
> - 한 가지 핵심 수칙.
> - 예시:
>   - 100% Tie-off 원칙 (안전대 후크 절대 분리 금지)
>
> **[작업 전 안전조치 확인 (3건)]**
> - 보호구·기계·환경.
> - 예시:
>   - [object Object],[object Object],[object Object]
>
> **[참석자 명단·서명]**
> - 전원 자필 서명 (외국인 모국어).
> - 예시:
>   - [object Object],[object Object],[object Object]
>
