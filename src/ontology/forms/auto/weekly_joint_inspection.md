## 2. 합동 안전보건점검 (산안법 제64조 ① 4호 + 시행규칙 제82조 (건설 2개월 1회))

| 항목 | 내용 |
|---|---|
| 점검 일시 *(필수)* | |
| 참석자 (3자 1명씩) *(필수)* | |
| 점검 범위 *(필수)* | |
| 점검 결과 *(필수)* | |
| 개선 조치 계획 *(필수)* | |

> **📝 작성 가이드**:
>
> **[점검 일시]**
> - 건설 2개월 1회 / 기타 분기 1회.
> - 예시:
>   - 2026-04-29 14:00~16:00
>
> **[참석자 (3자 1명씩)]**
> - 도급인 + 관계수급인 + 도급인·수급인 근로자 각 1명.
> - 예시:
>   - 도급인: 김안전 / 수급인: 박감독(우송) / 근로자: 이근로(도급인) + 박작업(수급인)
>
> **[점검 범위]**
> - 공동작업 + 혼재작업.
> - 예시:
>   - B동 골조-마감 혼재구역, 양중작업 + 외벽도장 동시
>
> **[점검 결과]**
> - 위험요인·미흡사항·우수사례.
> - 예시:
>   - 1) 양중구역 출입통제 미흡 → 펜스 설치, 2) 도장작업 환기 부족 → 송풍기 추가
>
> **[개선 조치 계획]**
> - 항목별 책임자·기한·예산.
> - 예시:
>   - 1) 출입통제 펜스 - 박감독, 2026-04-30, 50만원, 2) 송풍기 - 김도장, 2026-05-01, 100만원
>
