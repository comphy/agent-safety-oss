## 2. 위험성평가 절차 (위험성평가 고시 제13조)

| 항목 | 내용 |
|---|---|
| 평가 대상·범위 *(필수)* | |
| 평가팀 구성 *(필수)* | |
| 평가 방법 *(필수)* | |
| 평가 주기 *(필수)* | |
| 감소대책 위계 *(필수)* | |
| 근로자 참여 *(필수)* | |

> **📝 작성 가이드**:
>
> **[평가 대상·범위]**
> - 전 작업·공정 + 비정형 작업 포함.
> - 예시:
>   - 전 공정(굴착·골조·마감) + 비정형(긴급보수·청소)
>
> **[평가팀 구성]**
> - 사업주·관리감독자·작업자·안전관리자 + 외부전문가(필요시).
> - 예시:
>   - 사업주 1, 관리감독자 2, 작업자대표 3, 안전관리자 1
>
> **[평가 방법]**
> - 빈도·강도법(5×4) 또는 KRAS·체크리스트.
> - 예시:
>   - 빈도(1~5) × 강도(1~4) 매트릭스, 위험도 12 이상 우선조치
>
> **[평가 주기]**
> - 최초 + 정기(연1회) + 상시(매월·매주·매일) + 수시(변경시).
> - 예시:
>   - 최초 착공시, 정기 매년 12월, 상시 매월·매주·매일, 수시 변경시
>
> **[감소대책 위계]**
> - 제거 → 대체 → 공학적 대책 → 관리적 대책 → 개인보호구 순으로 적용.
> - 예시:
>   - 1순위 제거(공정변경), 2순위 대체(저위험물질), 3순위 공학적(방호장치), 4순위 관리적, 5순위 PPE
>
> **[근로자 참여]**
> - 고시 제16조 (의견청취·참여 의무).
> - 예시:
>   - TBM에서 5분 의견청취, 월 1회 협의회
>
